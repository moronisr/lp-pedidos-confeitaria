# lp-pedidos-confeitaria

Landing page de pedidos para uma confeitaria da região metropolitana de Belém. O objetivo da página é um só: levar o visitante ao pedido no canal certo, sem dispersão. Versão sanitizada, com marca e contatos fictícios.

## Problema

Os pedidos chegavam por canais diferentes, misturados com dúvidas e orçamentos. Não havia catálogo claro nem caminho único de ação, o que fazia o cliente desistir ou perguntar o básico várias vezes.

## O que a página faz

**Catálogo direto.** Produtos, tamanhos e faixas de preço visíveis sem precisar perguntar.

**Caminho único.** Um botão principal de pedido, repetido ao longo da rolagem, em vez de vários canais concorrentes.

**Mensagem pré-preenchida.** O botão abre a conversa já com o item escolhido, o que reduz ida e volta.

**Dúvidas antecipadas.** Prazo, entrega e formas de pagamento respondidos na própria página.

## Stack

HTML · CSS · JavaScript · layout responsivo, pensado primeiro para o celular

## Como usar

Abra `index.html` no navegador ou publique a pasta em qualquer hospedagem estática.

## Sanitização

Nome da empresa, logo, fotos, preços e números de contato foram substituídos por exemplos fictícios.
